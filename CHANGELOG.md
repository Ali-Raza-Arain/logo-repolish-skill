# Changelog

## 1.0.0 (2026-10-23)

First public release.

- `vectorize.py`: precise single and multi-colour vectors with exact lines on an angle grid, true corners,
  smoothed curves and exact, size-matched circles.
- `compare.py`: difference map and close-ups against the source.
- `audit.py`: stroke weights, gaps between facing edges, holes, off-grid angles, near-alignment, small sizes.
- `export_kit.py`, `lockups.py`, `icons.py`, `profiles.py`, `covers.py`: the brand kit.
- `upscale.py`: hybrid Real-ESRGAN upscaling for 3D and metallic logos.
- Claude Code plugin and marketplace manifests, smoke test, demo mark and full documentation.
